# 装修AI小程序前端

基于 Uniapp + Vue3 的装修AI助手微信小程序

## 技术栈

- Uniapp (Vue 3)
- Pinia 状态管理
- dayjs 时间处理

## 开发

```bash
# 安装依赖
npm install

# 开发微信小程序
npm run dev:mp-weixin

# 开发 H5
npm run dev:h5

# 构建微信小程序
npm run build:mp-weixin
```

## 目录结构

```
src/
├── pages/          # 页面
├── components/     # 组件
├── api/            # API请求
├── store/          # 状态管理
├── utils/          # 工具函数
├── styles/         # 样式
└── App.vue         # 应用入口
```
